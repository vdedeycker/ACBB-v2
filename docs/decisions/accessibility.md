# Accessibility Decisions

## Status

Active


## Audience

The website must remain usable by visitors with varying levels of
technical familiarity and ability.


## Core Requirements

Use semantic HTML whenever possible.

Maintain:

- readable text
- sufficient contrast
- keyboard accessibility
- visible focus states
- logical heading hierarchy
- meaningful link labels
- meaningful button labels
- appropriate image alternative text


## Typography

Body text should normally be at least 16px.


## Color

Never rely on color alone to communicate meaning.

Red must remain readable against its background.

Accessibility takes priority over strict color usage.


## Interaction

Interactive elements must be clearly recognizable.

Avoid interactions that require discovering hidden gestures or
non-standard behaviors.


## Motion

Avoid unnecessary motion.

Do not make animation necessary to understand or operate the website.


## Simplicity

Accessibility also includes cognitive simplicity.

Prefer:

- explicit wording
- predictable navigation
- short sections
- clear actions
- consistent interfaces
