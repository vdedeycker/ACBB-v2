# ACBB Design System

## Design Direction

The website should take UX and visual inspiration from:

https://www.whatsapp.com/

Do not clone or reproduce the WhatsApp website.

Use it only as inspiration for:

- simplicity
- generous spacing
- typography hierarchy
- rounded visual elements
- photography usage
- alternating content sections
- clear calls to action
- intuitive responsive layouts

The website must retain its own ACBB identity.


## Brand Personality

The ACBB website should feel:

- modern
- sporty
- welcoming
- human
- simple
- lightweight
- accessible

The website should feel like a local athletics club,
not like a corporate website or software application.


## Color Palette

### Primary red

`#D94A4A`

Used for:

- primary CTA buttons
- important links
- active states
- selected elements
- small visual accents

Avoid excessive large red backgrounds.


### Primary red hover

`#C63F3F`


### Soft red

`#F8E5E3`

Used for subtle highlighted sections when appropriate.


### Warm beige

`#FCF5EB`

Primary warm background color.


### White

`#FFFFFF`


### Dark

`#111B21`

Used primarily for:

- headings
- body text
- navigation
- dark sections where appropriate


## Color Balance

The interface should remain visually calm.

As a general visual principle, prefer approximately:

- 70% beige / white
- 20% dark
- 10% red

This is a guideline rather than a mathematical requirement.

Red communicates athletics, energy and the ACBB identity,
but must not visually overwhelm the visitor.


## ACBB Logo

The original ACBB logo must remain unchanged.

Do not recolor, redraw, distort, crop, rotate, or recreate the logo.

Maintain sufficient whitespace around the logo.


## Typography

Use a modern, highly readable sans-serif typeface.

Typography should use:

- large headings
- short headings
- clear hierarchy
- comfortable line height
- body text of at least 16px

Avoid long blocks of text whenever concise content is sufficient.


## Layout

Use:

- generous whitespace
- clear vertical sections
- large authentic photography
- rounded images
- simple layouts
- limited visual density
- alternating text and image sections where appropriate

Desktop layouts may use two columns.

Mobile layouts should naturally collapse to one column.


## Cards

Do not turn every piece of content into a card.

Cards should only be used when they improve comprehension or grouping.

Prefer simple content sections whenever possible.


## Buttons and Links

Important actions must be immediately recognizable.

Prefer explicit labels such as:

- "Voir les horaires"
- "Rejoindre le club"
- "Voir les compétitions"
- "Nous contacter"
- "Télécharger le document"

Avoid vague labels such as:

- "Découvrir"
- "Cliquez ici"
- "En savoir plus"

when a more explicit action is possible.


## Photography

Prefer authentic ACBB photography.

Useful subjects include:

- training sessions
- competitions
- athletics disciplines
- club events
- groups
- track and field environments

Avoid generic stock photography when authentic club material is
available.

Use large photography where it contributes to the experience.


## Content Density

Never overload a screen with information.

Prefer:

- short sections
- clear headings
- concise paragraphs
- progressive disclosure
- obvious calls to action

The homepage is primarily an orientation and showcase page.


## Responsive Design

Use a mobile-first approach.

The website must work comfortably on:

- smartphones
- tablets
- laptops
- desktop monitors

Avoid horizontal scrolling.

Interactive elements must provide comfortable touch targets.


## Motion

Animation must remain subtle and optional.

Acceptable:

- simple hover transitions
- lightweight state transitions
- subtle appearance effects when justified

Avoid:

- parallax
- animated backgrounds
- complex scroll effects
- distracting movement
- decorative animation libraries


## Avoid

Avoid unless specifically justified:

- glassmorphism
- neumorphism
- excessive gradients
- excessive shadows
- excessive borders
- tiny typography
- dense navigation
- unnecessary dropdowns
- carousels
- aggressive red surfaces
- unnecessary visual effects
- unnecessary JavaScript
